# 幻核动漫纯前端路由框架 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在不改变现有首页视觉的前提下，把幻核动漫官网迁移为 Vite、React 与 React Router 驱动的纯前端四页应用，并让背景视频在站内路由切换时保持同一个 DOM 节点。

**Architecture:** 浏览器只创建一个 `RouterProvider`。根路由渲染长期挂载的 `AppLayout`，其中包含背景视频、遮罩、颗粒层、桌面导航、移动导航与 `<Outlet />`；四个页面只替换 Outlet 内容。首页复用当前结构、类名、文案和样式，其他页面只建立最小中文内容骨架。Vite 产物继续输出到 `dist`，Sites 对未知请求回退到 `index.html`，交给前端路由处理。

**Tech Stack:** Vite、React、React DOM、React Router、Vitest、Testing Library、jsdom、Sites 静态托管

**Spec:** `docs/superpowers/specs/2026-09-11-纯前端路由框架-design.md`

**Global Constraints:**

- 不接入后端、数据库、表单提交、远程数据接口或账号系统。
- 首页已有可见结构、文案、类名、响应式断点和视觉参数保持不变。
- 背景视频继续使用当前地址；站内切换路由时不得重新创建视频元素。
- 页面可见文案全部使用中文；技术文件名、依赖名和标准无障碍属性值不受此限制。
- 路由固定为 `/`、`/services`、`/cases`、`/contact` 与未知地址处理。
- 联系页只显示“二维码位置”占位，不创建虚构二维码、联系方式或案例内容。
- 所有源文件保存在当前项目目录内，构建输出仍为 `dist`。
