# 幻核动漫纯前端路由框架设计说明

## 目标

将现有幻核动漫静态单页迁移为 React Router 驱动的纯前端多路由应用。首页的视觉、文案、动效、响应式行为与背景视频地址保持不变；新增服务、案例视频、联系三个页面骨架，不接入后端、数据库或远程数据接口。

## 技术选择

使用 Vite、React 与 React Router。Vite 负责本地开发和静态构建，React Router 负责浏览器端路由。发布产物仍输出到 `dist`，继续使用现有 Sites 项目与项目编号。

不采用 Next.js：本项目没有服务端渲染、服务端接口或数据层需求，React Router 能以更少的依赖和配置满足全局布局持久化与四页路由需求。

## 路由结构

应用包含以下路由：

- `/`：首页。迁移现有首页的完整结构，保留全部现有类名和样式规则。
- `/services`：服务页骨架，仅包含页面标题和后续内容承载区。
- `/cases`：案例视频页骨架，仅包含页面标题和后续视频内容承载区。
- `/contact`：联系页骨架，包含二维码展示占位区，但不生成或虚构二维码。
- `*`：未知地址页面，提供返回首页的入口。

顶部桌面导航和移动导航均改用 React Router 的路由链接。当前路由对应的导航项显示现有三点选中标记。品牌文字链接返回首页；“洽谈合作”和“开始合作”进入联系页。

## 全局布局与背景持久化

根路由使用一个长期挂载的 `AppLayout`：

1. `BackgroundVideo` 在布局最外层只创建一次，使用现有视频地址和现有背景遮罩、颗粒层。
2. `SiteHeader` 与移动菜单位于同一全局布局中。
3. `<Outlet />` 只替换当前页面内容。

所有页面跳转都使用客户端路由链接，不使用普通文档跳转。切换 `/`、`/services`、`/cases`、`/contact` 时，根布局不卸载，因此背景视频 DOM 节点保持同一引用，不重新创建、不更换地址、不触发页面级重新加载。

直接在浏览器地址栏打开子路由属于一次正常首屏加载；进入应用后的站内路由切换保持背景视频连续。

## 文件边界

- `index.html`：Vite 文档入口和现有页面元信息。
- `src/main.jsx`：创建 React 根节点和浏览器路由。
- `src/AppLayout.jsx`：全局页面结构、背景视频、导航和移动菜单状态。
- `src/pages/HomePage.jsx`：现有首页主体与底部数据。
- `src/pages/ServicesPage.jsx`：服务页骨架。
- `src/pages/CasesPage.jsx`：案例视频页骨架。
- `src/pages/ContactPage.jsx`：联系页及二维码占位区。
- `src/pages/NotFoundPage.jsx`：未知地址处理。
- `src/styles.css`：原首页样式原样迁移，并仅追加新页面骨架所需样式。
- `public/fonts/GeistPixel-Circle.woff2`：现有本地字体资源。
- `tests/router.test.jsx`：路由与背景持久化测试。
- `.openai/hosting.json`：继续使用 `dist`，增加单页应用未知路径回退。

## 首页保真规则

首页保留以下内容，不做视觉重构：

- 单视口布局、视频背景、遮罩与颗粒层。
- “幻核动漫”文字品牌、胶囊导航和移动菜单。
- 信任徽章、主标题、业务说明、合作按钮。
- 四项能力数据、计数动画和减少动态效果支持。
- 现有断点、颜色、字号、间距、阴影与动画规则。

为接入路由允许把原网页标签转换为等价 JSX，并把站内链接替换为 `NavLink` 或 `Link`；不得借迁移调整首页视觉参数。

## 页面骨架规则

三个新页面沿用全局背景和导航，只提供最小可识别内容：

- 服务页显示“服务”和一个空内容承载区。
- 案例页显示“案例视频”和一个空视频承载区。
- 联系页显示“联系我们”和一个标注为“二维码位置”的占位区。

骨架不包含虚构案例、服务价格、联系方式、二维码图片、表单、上传、登录或数据请求。

## 状态与错误处理

- 移动菜单状态由 `AppLayout` 管理，路由切换后自动关闭。
- 计数动画只在首页组件挂载时执行，并继续尊重减少动态效果偏好。
- 未知路由显示中文提示和返回首页链接。
- Sites 静态托管配置使用单页应用回退，确保直接访问 `/services`、`/cases` 或 `/contact` 时由前端路由接管。

## 测试与验收

- 四个指定路由与未知地址路由均能渲染。
- 首页关键文案、类名、视频地址和现有样式合同保持不变。
- 从首页导航到任一子页面后，背景视频元素仍是切换前的同一个 DOM 节点。
- 桌面和移动导航使用客户端路由，当前项状态正确。
- 联系页只显示二维码占位，不包含虚构二维码资源。
- `npm test`、`npm run build` 和 Sites 静态归档验证通过。
